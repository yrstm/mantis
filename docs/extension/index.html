Copy the current page or selected text as Markdown.

Mantis runs when you click its toolbar button. It reads the page already rendered in the active tab, converts it locally, shows a preview, and copies the Markdown to your clipboard.

Page or selection → Markdown → clipboard.

Install

$ Chrome Web Store — not published
Deferred

The Manifest V3 build passes local tests. A public install link will be added after store submission.

Capabilities

Capture

Reads the current HTTP(S) tab after you click the extension. A useful text selection takes priority over the full page.

Format

Keeps headings, paragraphs, lists, quotes, code, links, content images, and data tables in reading order.

Details

Adds the source URL and title, capture mode, confidence, warnings, and a rough token estimate.

Clipboard

Copies automatically when the browser allows it. The panel keeps a manual copy control when automatic clipboard access fails.

Permissions

Three permissions. No persistent site access and no third-party host permission.

activeTab
Read the current tab after you click Mantis.
scripting
Run the packaged extractor in that tab.
clipboardWrite
Copy the Markdown result.

No external page fallback. The extension does not send page URLs or page content to Mantis or a proxy service.

Limits

Restricted URLs

Browser-internal pages, extension stores, and other protected URLs cannot be captured.

Page state

Hidden, unloaded, or inaccessible frame content is outside the rendered DOM snapshot.

Extraction

Unusual layouts can produce partial or low-confidence output. Mantis is not a verbatim archive.

Images

Image references and alt text are kept. The extension does not run OCR or image analysis.
